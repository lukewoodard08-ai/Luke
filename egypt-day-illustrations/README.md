# A Day in Ancient Egypt — illustration set

95 crude MS-Paint-style stills, one per timestamp in the script. 16:9, 2048x1152 PNG, plain white background, thick wobbly black outlines, stick figures, flat fills.

## Timestamps

The script arrived as two transcripts and the second one restarted at `0:00`. Part 1 ends at `5:32`, so every part 2 timestamp is shifted by **+5:39** and the set runs continuously from `0:00` to `9:32`. Part 2's `0:00` is `5:39`, its `1:00` is `6:39`, and so on. `shot-list.csv` keeps both the corrected and the original timestamp.

## Files

- `shot-list.csv` — running order, corrected timestamp, original timestamp, caption, filename, full-res URL
- `manifest.json` — same data plus the generation job id for each still
- `thumbs/` — 480x270 JPEG previews; full-resolution PNGs are at the URLs in the shot list
- `gallery.html` — self-contained contact sheet of all 95 stills

Generated with Higgsfield (`z_image`), 16:9, one job per timestamp.
